# 🎨 CSS Animation Examples

A simple project showcasing different **CSS animations** using HTML and CSS.

### Features
- Color change animation
- Move and rotate effects
- Pulse and fade effects
- Loading spinner
- Square path animation
- Voice assistant-style animation

### Tech Used
- HTML5
- CSS3
- CSS Animations
